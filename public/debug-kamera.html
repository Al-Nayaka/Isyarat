Cara membaca hasil

  1. Tangan terdeteksi = 0 padahal tangan jelas di kamera: masalah MediaPipe/pencahayaan/posisi.
  2. currentTime tidak bergerak: video berhenti (autoplay diblokir) — klik video, lalu muat ulang.
  3. Tangan terdeteksi ≥ 1 tetapi aplikasi bilang “Tangan belum terlihat”: masalah ada di alur engine aplikasi, bukan kamera.
  4. Pastikan kedua tangan masuk frame dan berjarak ±40–80 cm dari kamera.
  5. Jika GPU bermasalah, buka /debug-kamera.html?delegate=cpu atau /?delegate=cpu untuk memaksa CPU.
  6. Jika tetap 0, coba sensitivitas lebih rendah: /debug-kamera.html?delegate=cpu&min=0.3.
  7. Jika masih 0, coba MediaPipe legacy: /debug-kamera.html?delegate=cpu&bundle=legacy.
